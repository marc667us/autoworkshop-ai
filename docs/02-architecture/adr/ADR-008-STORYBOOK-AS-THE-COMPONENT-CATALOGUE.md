# ADR-008 — Storybook as the component catalogue

**Status:** Accepted · **Date:** 2026-07-25 · **Release:** 0.1

## Context

`01 (1).txt` §71 requires every production component to have a story.

## Decision

Storybook, with a story per component covering variants, states, responsive behaviour and accessibility notes.

## Consequences

Components are developed in isolation and documented by construction. A new shared component without a story fails review.
